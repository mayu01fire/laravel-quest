# TaskFlow

Laravelで開発した、個人向けのタスク管理Webアプリケーションです。

タスクの登録・編集・削除に加え、優先度や期限、カテゴリを設定してタスクを整理できます。

検索・絞り込み・並び替え機能を備え、PC・スマートフォンの両方で利用しやすい画面を目指して開発しました。

## 主な機能

- **ユーザー認証**：ユーザー登録・ログイン・ログアウト
- **プロフィール管理**：名前・メールアドレス変更、パスワード変更、アカウント削除
- **タスク管理**：登録・一覧表示・詳細表示・編集・削除
- **完了状態の管理**：完了・未完了の切り替え
- **優先度設定**：高・中・低の3段階
- **期限管理**：期限の設定・変更・解除
- **カテゴリ管理**：カテゴリの追加・名前変更・削除
- **検索・絞り込み**：タスク名、カテゴリ、優先度、完了状態
- **並び替え**：新しい順・古い順・優先度順
- **進捗表示**：タスク総数、完了数、未完了数、完了率
- **レスポンシブ対応**：PC・スマートフォンに対応

## セキュリティ対策

- Laravel Policyを利用したタスクのアクセス制御
- 他ユーザーのタスクの閲覧・編集・削除・完了状態変更の禁止
- 自分が所有するカテゴリのみ利用できるバリデーション
- フォーム入力値のバリデーション
- 認証が必要な画面・操作へのアクセス制限

## セットアップ

### 必要な環境

- PHP 8.2以上（開発環境：PHP 8.4.27）
- Composer
- Node.js / npm
- MySQL
- Git

### 1. リポジトリの取得

```bash
git clone https://github.com/m-omae/laravel-quest.git
cd laravel-quest
```

### 2. 依存パッケージのインストール

```bash
composer install
npm install
```

### 3. 環境設定

`.env.example` をコピーして `.env` を作成します。

Windows（PowerShell）：

```powershell
Copy-Item .env.example .env
```

macOS / Linux：

```bash
cp .env.example .env
```

アプリケーションキーを生成します。

```bash
php artisan key:generate
```

### 4. データベースの準備

MySQLで空のデータベースを作成し、`.env` に接続情報を設定します。

```dotenv
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=taskflow
DB_USERNAME=your_username
DB_PASSWORD=your_password
```

※ 上記は設定例です。実際のMySQL環境に合わせて変更してください。

テーブルを作成します。

```bash
php artisan migrate
```

### 5. フロントエンドのビルド

```bash
npm run build
```

### 6. アプリケーションの起動

```bash
php artisan serve
```

ブラウザで `http://127.0.0.1:8000` にアクセスしてください。

### 7. テストの実行

```bash
php artisan test
```

※ テスト実行前に、テスト用データベースの設定を確認してください。既存の開発・本番データベースをテストに使用しないでください。

## 開発で工夫した点

### 1. ユーザーごとのデータ分離

ログインユーザーに紐づくタスクのみ取得する構成とし、Policyによる認可を組み合わせて、他ユーザーのデータを操作できないようにしました。

### 2. データの整合性

カテゴリ削除時には、紐づくタスク自体は削除せず、カテゴリとの関連付けのみ解除する仕様にしています。

### 3. 自動テストによる品質確認

正常系だけでなく、不正アクセスや入力エラー、境界値などを検証するFeatureテストを追加しました。

### 4. レスポンシブデザイン

タスク一覧、作成、編集、詳細、カテゴリ管理画面をPCとスマートフォンの双方で確認し、画面幅に合わせてレイアウトを調整しました。
